# Custom AI — OpenAI-compatible Implementation Plan

> **For agentic workers:** Execute tasks in order; preserve unrelated Chatwoot sync changes. No commits/push without an explicit request.

**Goal:** Add an independent Custom AI provider supporting a full chat-completions endpoint, arbitrary model ID, optional bearer key, draft connection tests and model discovery.

**Architecture:** Reuse the existing OpenAI-compatible HTTP implementation under provider `custom`. Normalize either a base URL or a full `/chat/completions` URL once, preserving query parameters. Store endpoint/model in existing tenant settings and encrypt keys with the existing mechanism. Saved custom configuration must also work in Analyzer, without requiring an API key.

**Tech Stack:** Go/Gin/GORM; Vue 3/Vuetify/TypeScript; Go httptest and Vitest.

## Approved behavior

- Provider dropdown adds `Custom AI — OpenAI-compatible`.
- Custom endpoint accepts HTTP(S) URLs, including the user's complete `/v1/chat/completions` URL. No repeated suffix. Require endpoint and nonempty model for save/test.
- Custom model accepts typed IDs; discovery through sibling `/models` is optional and cannot block saving a typed model.
- API key optional: omit Authorization when absent; encrypt nonempty keys. An explicit `clear_api_key` clears saved credentials; masked key retains the saved key only for the same provider/endpoint.
- Switching provider/endpoint must not silently forward another provider's saved key.
- Test requests use current form values without saving settings. Existing empty-body saved-config tests remain supported.
- Custom requests use `max_tokens`; existing OpenAI requests retain `max_completion_tokens`.
- Custom timeout is editable from 5–600 seconds (default 120), stored as `ai_timeout_seconds`.
  Applies to the entire completion/retry budget, batch and connection checks. Discovery stays 20 seconds.
  UI test budget is selected timeout + 10 seconds; local CQA proxy read timeout is 620 seconds.
- Default-provider behavior remains compatible. Custom model discovery has no hardcoded Claude/OpenAI fallback list.
